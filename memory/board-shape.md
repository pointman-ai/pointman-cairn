name: board-shape
description: The rules a tidy project follows; check them on every pass
metadata:
  type: feedback
---

- Every task sits under an epic. No loose tasks.
- Every open item has an owner, a start date and a target date.
- Active items (Todo, In progress, In review) carry the current sprint. Use a sprint name that exists, because an unknown one is refused.
- A step only a person can take (a decision, a key, an account, a payment) is an item owned by that person, so it shows in their own list.
- An epic's target is its latest open task's target. When tasks move, move the epic too.

**Why:** people read the board to know what's happening without asking. One loose or undated item and they stop trusting it.
**How to apply:** after filing anything, and on every sweep, re-check these five. Related: [[closing-with-evidence]], [[sweeping-a-board]].
